# Morgan's Changes — MAINSTREET-RP Handover

This repository is the **handover record** for the work Morgan did on the
MAINSTREET-RP FiveM server. It exists so Stim (and anyone else picking the
server up) can see what was added, what was changed, what was removed, and
which commands come with each piece.

It is **documentation only**. No server code lives here. The code lives in the
MAINSTREET-RP repository, on the `dev` branch.

## Contents

| File | What's in it |
|---|---|
| [`MORGAN-SYSTEMS.md`](MORGAN-SYSTEMS.md) | The main handover doc: systems built, systems changed, commands and who can run them |
| [`docs/commands.md`](docs/commands.md) | Command reference on its own, for quick lookup |
| [`docs/SOURCING.md`](docs/SOURCING.md) | Where each fact in here came from, and what still needs filling in from the source repo |

## Status

The handover is **partially complete**. The high-level picture (systems,
resources, counts, what was removed) is recorded. The exact names of all 18
live commands, the third-eye/interaction detail, and the UI specifics still
need to be pulled from the MAINSTREET-RP working copy — see
[`docs/SOURCING.md`](docs/SOURCING.md) for exactly what's missing and the two
ways to close the gap.

Do not treat a blank in this repo as "nothing was changed there." Treat it as
"not yet transcribed."
